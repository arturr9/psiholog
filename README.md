# Ислам — психолог

Локальный адаптивный лендинг. Без библиотек и сборки. Montserrat подключён локально с лицензией OFL.

## Открыть

В этой папке выполните `npm start`, затем откройте http://127.0.0.1:3000. Установка зависимостей не нужна. Также можно открыть `index.html` напрямую.

## Изменить

- `content.js` — все тексты, темы, навигация, контакты и пути к изображениям.
- `content.js → contact.channels[0].url` — единая основная контактная ссылка. Кнопки используют её автоматически. Другие реальные способы связи можно добавить в массив `channels`.
- `content.js → images` — фотография, альтернативный текст и исходные размеры. Текущий файл: `assets/islam-portrait.png` (оригинал пользователя).
- `content.js → topics.items[].image` — путь к фотографии вместо абстрактной иллюстрации. `null` оставляет неоновую ленту.
- `styles.css → @font-face` — шрифт; `:root` — палитра и основные параметры оформления.
- `app.js → ribbon()` — статичная векторная геометрия лент.

Временные тексты отмечены комментариями только в `content.js`. Сайт не опубликован.

## Проверка

`npm run check` проверяет синтаксис JavaScript. Сценарии приёмки: навигация, мобильное меню (включая Escape), все восемь тем, повторное закрытие, открытие только одной темы, фокус с клавиатуры, reduced motion и отсутствие горизонтальной прокрутки на 320–1920 px.

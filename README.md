# Ислам — психолог

Локальный адаптивный лендинг. Без библиотек и сборки. Montserrat подключён локально с лицензией OFL.

## Открыть

В этой папке выполните `npm start`, затем откройте http://127.0.0.1:3000. Установка зависимостей не нужна. Также можно открыть `index.html` напрямую.

## Изменить

- `content.js` — все тексты, темы, навигация, контакты и пути к изображениям.
- `content.js → contact.channels[0].url` — основная контактная ссылка (Instagram). Все кнопки «Связаться» используют её автоматически. Остальные каналы массива `channels` выводятся в футере.
- `content.js → images` — фотография, альтернативный текст и исходные размеры. Текущий файл: `assets/islam-portrait.png` (оригинал пользователя).
- `content.js → about.approachLines` — строки под заголовком «Мой подход».
- `content.js → education.groups` — раскрывающиеся блоки. Поддерживаются `text` (абзац), `intro` (вступление) и `lines` (маркированный список).
- `styles.css → @font-face` — шрифт; `:root` — палитра и основные параметры оформления.
- `app.js` — сборка разметки из `content.js`, раскрывающиеся темы и меню.
- `granat-smoke.js` — анимированный гранатовый дым на плашке «Найти опору.». Блок находится по классу `.hero-highlight`, который задаётся в `index.html` через `window.GRANAT_SMOKE_SELECTOR`. Скрипт подключён последним, чтобы разметка уже существовала. Без WebGL остаётся статичная заливка `#8e1238`.
- `build.mjs` — копирует файлы в `public/` для Vercel; при добавлении нового JS-файла его нужно внести в список.

Временные тексты отмечены комментариями только в `content.js`. Сайт не опубликован.

## Проверка

`npm run check` проверяет синтаксис JavaScript, включая `granat-smoke.js`. `npm run build` собирает `public/`. Сценарии приёмки: навигация, мобильное меню (включая Escape), все восемь тем, повторное закрытие, открытие только одной темы, фокус с клавиатуры, reduced motion, наличие гранатового дыма (или статичной заливки без WebGL), четыре блока «Образования», три контакта в футере и отсутствие горизонтальной прокрутки на 320–1920 px.
